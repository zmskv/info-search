\CWHeader{Лабораторная работа \textnumero 3 \enquote{Токенизация}}

Необходимо написать модуль для разбиения текстов на токены с учётом специфики
языка (знаки препинания, цифры, сокращения) и протестировать токенизатор на
документах из корпуса.

\begin{itemize}
    \item Токенизатор должен быть гибким и настроенным на конкретную предметную
    область --- русскоязычные статьи.
    \item Нужно учесть нюансы: составные слова, аббревиатуры, числа, знаки
    препинания.
    \item Проверить работу на документах корпуса: количество токенов, их
    средняя длина, скорость работы.
\end{itemize}
